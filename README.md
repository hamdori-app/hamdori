# Hamdori

Hamdori is a 3D hamster desktop pet for Mac and Windows. A lifelike hamster lives in a borderless, see-through window on your desktop. It loves a gentle rub, gathers seeds while you type, and takes breaks with you.

- Website and purchase: https://hamdori.com
- Download: https://hamdori.com/en/download/
- Support: support@hamdori.com

This repository only hosts the installers and update files.
